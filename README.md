# 📝 To-Do List App

A clean and simple To-Do List web app built with HTML, CSS, and JavaScript. Add tasks, view them in a list, and remove them with a click. Great for organizing daily goals and boosting productivity.

## ✨ Features
- Add tasks instantly
- Remove tasks with a click
- Minimal and responsive design
- Beginner-friendly codebase

## 📌 How to Use
1. Type your task in the input box.
2. Click "Add" to include it in the list.
3. Click any task to remove it.
